MODULE 1B: ER DIAGRAM + POSTGRESQL SCHEMA
================================================================================

DATABASE STRUCTURE:

TABLES (8):
1. users - Customer accounts with authentication
   - user_id (PK), email (UK), password_hash, names, phone, etc.

2. airlines - Airline companies
   - airline_id (PK), airline_name, airline_code (UK), contact info

3. flights - Flight schedules
   - flight_id (PK), flight_number (UK), airline_id (FK), 
     departure/arrival airports and times, status

4. travel_classes - Service tiers
   - travel_class_id (PK), class_name (UK), base_price, 
     baggage_allowance, amenities

5. seats - Seat inventory
   - seat_id (PK), flight_id (FK), seat_number, 
     travel_class_id (FK), availability, characteristics

6. bookings - Reservations
   - booking_id (PK), booking_reference (UK), user_id (FK),
     flight_id (FK), seat_id (FK), total_amount, status

7. payments - Transactions
   - payment_id (PK), booking_id (FK), user_id (FK),
     transaction_id (UK), amount, method, status

8. audit_logs - Change tracking
   - log_id (PK), user_id (FK), action, table_name,
     old_values (JSONB), new_values (JSONB)

CUSTOM TYPES (4 ENUMS):
- booking_status_enum (pending, confirmed, cancelled, completed)
- payment_status_enum (pending, completed, failed, refunded)
- flight_status_enum (scheduled, delayed, cancelled, departed, arrived)
- payment_method_enum (credit_card, debit_card, paypal, bank_transfer)

KEY RELATIONSHIPS:
- Users → Bookings (1:N)
- Airlines → Flights (1:N)
- Flights → Seats (1:N, CASCADE DELETE)
- Bookings → Seats (N:1)
- Bookings → Payments (1:1)
- Travel Classes → Seats (1:N)

CONSTRAINTS:
✅ Primary keys on all tables
✅ Foreign key relationships with referential integrity
✅ Unique constraints (email, booking_reference, transaction_id)
✅ Check constraints (positive amounts, valid dates, different airports)
✅ Email format validation
✅ NOT NULL on required fields

INDEXES:
✅ Primary key indexes (automatic)
✅ Foreign key indexes
✅ Email and frequent flyer lookups
✅ Flight number and date searches
✅ Booking reference lookups
✅ Partial indexes for available seats

TRIGGERS:
✅ Auto-update updated_at timestamps

VIEWS:
